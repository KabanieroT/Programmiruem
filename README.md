# Programmiruem

Учебный проект на Python.

## Требования
- Python 3.x
- uv (менеджер пакетов)

## Установка
1. Клонировать репозиторий:
   git clone https://github.com/KabanieroT/Programmiruem.git
2. Перейти в папку:
   cd Programmiruem
3. Установить зависимости:
   uv sync

## Запуск
uv run python src/prz/__init__.py
